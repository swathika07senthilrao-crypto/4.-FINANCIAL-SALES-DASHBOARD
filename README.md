# 4.-FINANCIAL-SALES-DASHBOARD

Sales Financial Dashboard – Power BI
📌 Project Overview

The Sales Financial Dashboard is an interactive Power BI dashboard designed to analyze sales performance, profitability, product performance, and daily sales trends.The dashboard provides a clear view of key business metrics and allows users to interact with the data using filters such as Year, Month, Payment Mode, and Sales Type.This project demonstrates practical skills in Power BI, data visualization, DAX, KPI analysis, interactive filtering, and business intelligence.

🎯 Project Objectives

The main objectives of this project are to:
Analyze overall sales performance
Track total sales and total profit
Monitor profit margins
Analyze sales trends over time
Identify top-performing products
Compare product performance by year
Analyze profitability across categories
Provide interactive filtering for business users
Present business insights through an easy-to-understand dashboard
🛠️ Tools & Technologies
Tool	Purpose
Power BI Desktop- Dashboard development and visualization
Power Query	- Data cleaning and transformation
DAX	Measures and KPI calculations
Excel/CSV	Source data

The dashboard includes important business KPIs such as:
Total Sales
Total Profit
Sales Growth %
Profit Margin %
Target vs Profit

These KPIs provide a quick overview of the company's financial performance.

🔹 Interactive Filters
Users can interact with the dashboard using:
Year
Month
Payment Mode
Sales Type

These filters dynamically update the dashboard visuals and allow users to perform focused analysis.

🔹 Sales Analysis
The dashboard includes:
Sales by Product
Daily Sales
Monthly Sales Trend
Sales performance across different time periods

These visuals help identify sales patterns and fluctuations.

🔹 Product Analysis

The dashboard provides product-level analysis through:
Top 10 Products by Year
Sales performance by product
Comparison of product performance across different years

This helps identify products that contribute significantly to overall sales.

🔹 Profitability Analysis

The dashboard includes:
Profit by Category
Profit Margin
Target vs Profit

This helps understand which categories generate higher profits and whether business performance is meeting targets.
